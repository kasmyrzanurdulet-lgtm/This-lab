# TUIS LAB

Қазақстан оқушыларына арналған интерактивті білім беру платформасының демо нұсқасы.

## Сайт

GitHub Pages жариялауы сәтті аяқталған соң сайт мына жерде ашылады:

https://kasmyrzanurdulet-lgtm.github.io/This-lab/

## Жергілікті іске қосу

```bash
pnpm install
pnpm run dev
```

Өндірістік құрастыру:

```bash
pnpm run build
```

GitHub Pages сайты `main` тармағына өзгеріс келген сайын GitHub Actions арқылы автоматты түрде жиналып жарияланады.

Supabase әзірше бапталмаған. Барлық demo күйі браузердің жергілікті қоймасында сақталады.
